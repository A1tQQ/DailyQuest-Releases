# DailyQuest

Локальный список задач с расписаниями, характеристиками и опытом. Аккаунт DailyQuest не требуется.

## Скачать

Откройте [последний релиз DailyQuest](https://github.com/A1tQQ/DailyQuest-Releases/releases/latest) и выберите файл для своего устройства:

- **Windows x64:** [A1tQQ.DailyQuest-win-Setup.exe](https://github.com/A1tQQ/DailyQuest-Releases/releases/latest/download/A1tQQ.DailyQuest-win-Setup.exe).
- **Android 8.0+ (ARM64 / x64):** [DailyQuest-android.apk](https://github.com/A1tQQ/DailyQuest-Releases/releases/latest/download/DailyQuest-android.apk).

На Android скачайте APK на телефон, откройте файл, при запросе разрешите установку из выбранного браузера или файлового менеджера и нажмите «Установить». Для напоминаний разрешите уведомления при запросе приложения.

Файлы `.nupkg` и `.json` служат для обновления приложения; для первой установки нужны EXE или APK. Обновления доступны внутри приложения: Windows предлагает скачивание и перезапуск, Android открывает системное подтверждение установки APK.

## Android 0.2.0

Первая экспериментальная версия. APK подписан постоянным ключом выпуска; сборка и проверки общей логики прошли. Запуск на физическом телефоне, системные уведомления, виджет и обновление APK на устройстве пока не проверены.

Данные хранятся локально на каждом устройстве. Автоматическая синхронизация между ПК и телефоном пока не добавлена. Экспортируйте резервную копию перед удалением приложения. Если установлена прежняя тестовая debug-копия Android, экспортируйте данные, удалите её, установите публичный APK и импортируйте данные.

Windows-установщик не имеет доверенной цифровой подписи; Windows может показать предупреждение при запуске.
